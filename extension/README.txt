SuperChrome for Chrome and Brave

Install: https://jdjuan.io/superchrome
Source and releases: https://github.com/jdjuan/SuperChrome

Keep the extracted folder in a permanent location. Open the browser extensions page, enable Developer mode and Load unpacked the folder with manifest.json. For optional video downloads, open Save and Copy Prompt.

Updates are detected from public GitHub releases when the popup opens, at most once per day; Check updates retries immediately. Copy update prompt guides replacement in place and reloading. Settings remain in browser storage. Updates are not installed automatically.
